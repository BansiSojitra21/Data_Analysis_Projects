# 🏠 Housing Price Analysis

> A Data Analysis project that explores housing market data to understand the factors influencing house prices through data cleaning, exploratory data analysis (EDA), and visualizations.

---

# 📌 Project Overview

Housing prices depend on various factors such as area, number of bedrooms, bathrooms, parking availability, furnishing status, and nearby facilities.

This project analyzes a housing dataset to identify trends, relationships, and insights that help understand what drives property prices.

---

# 🎯 Objectives

- Explore the housing dataset
- Clean and preprocess the data
- Handle missing values (if any)
- Understand numerical and categorical features
- Perform Exploratory Data Analysis (EDA)
- Identify relationships between housing features and price
- Generate business insights using visualizations

---

# 📂 Dataset

The dataset contains information such as:

# 📈 Key Insights

Some observations from the analysis include:

- Larger houses generally have higher prices.
- Houses with more bedrooms and bathrooms tend to be more expensive.
- Properties in preferred areas usually command higher prices.
- Amenities such as air conditioning, parking, and furnished status positively influence house prices.
- Several housing features are positively correlated with price.
