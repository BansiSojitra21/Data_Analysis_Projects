# 🚢 Titanic Data Analytics Project

> A complete Exploratory Data Analysis (EDA) project on the Titanic dataset using Python. This project focuses on data cleaning, preprocessing, visualization, and business insights to understand the factors that influenced passenger survival.

---

# 📌 Project Overview

The Titanic disaster is one of the most well-known historical events used in data analytics and data science. This project explores passenger information to identify patterns, trends, and relationships between different features and survival outcomes.

The analysis includes data cleaning, missing value treatment, exploratory data analysis (EDA), and visualization to generate meaningful business insights.

---

# 🎯 Project Objectives

- Understand the Titanic dataset
- Explore passenger demographics
- Clean and preprocess the dataset
- Handle missing values
- Perform Exploratory Data Analysis (EDA)
- Visualize survival patterns
- Generate meaningful insights

# 📂 Dataset

**Dataset:** Titanic Passenger Dataset

The dataset includes information such as:

- Passenger Class (Pclass)
- Name
- Sex
- Age
- SibSp (Siblings/Spouses)
- Parch (Parents/Children)
- Ticket
- Fare
- Cabin
- Embarked
- Survival Status

# 📈 Key Insights

Some important findings from the analysis include:

- Female passengers had a higher survival rate than male passengers.
- First-class passengers survived more frequently than passengers in lower classes.
- Younger passengers generally had better survival rates.
- Fare and passenger class showed a relationship with survival.
- Missing values in certain columns required preprocessing before analysis.
