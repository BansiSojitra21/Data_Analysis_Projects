# 🍽️ Restaurant Tips Data Analysis (EDA)

> An Exploratory Data Analysis (EDA) project using the Seaborn **Tips** dataset to understand customer tipping behaviour, spending patterns, and the factors that influence tip amounts.

---

# 📌 Project Overview

Tipping behaviour provides valuable insights into customer spending habits and restaurant operations. In this project, the popular **Seaborn Tips** dataset is analyzed to identify relationships between total bill, tip amount, gender, smoking status, meal time, and day of the week.

The project demonstrates the complete EDA workflow, from data inspection and feature engineering to visualization and business insights.

---

# 🎯 Project Objectives

- Understand the structure of the dataset
- Inspect data quality and missing values
- Perform feature engineering
- Explore customer tipping behaviour
- Visualize relationships between variables
- Generate meaningful business insights

---

# 📂 Dataset

**Dataset:** Seaborn Tips Dataset

The dataset contains restaurant billing information including:

- Total Bill
- Tip Amount
- Gender
- Smoker Status
- Day of the Week
- Meal Time (Lunch/Dinner)
- Party Size

---

# 💡 Key Insights

The analysis reveals several interesting patterns:

- Customers with higher bills generally leave higher tips.
- Dinner customers contribute more to restaurant revenue than lunch customers.
- Tip percentage varies slightly between lunch and dinner.
- Spending patterns differ across days of the week.
- Gender and smoking status influence average tipping behaviour.
- Party size shows a relationship with the total bill and tip amount.
