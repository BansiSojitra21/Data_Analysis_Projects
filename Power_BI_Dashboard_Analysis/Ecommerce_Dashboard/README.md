# 📊 E-Commerce Sales Dashboard

## 📌 Project Overview

This project presents an interactive **Power BI dashboard** built to analyze e-commerce sales performance. The dashboard transforms raw sales data into meaningful visual insights, helping users understand business performance, customer behaviour, and sales trends.

## 🎯 Objectives

* Analyze overall sales performance
* Monitor key business KPIs
* Identify top-performing products and categories
* Track sales across different regions
* Understand customer purchasing patterns
* Support data-driven business decisions

## 📂 Project Files

| File                  | Description                     |
| --------------------- | ------------------------------- |
| `ecom data.pbix`      | Power BI dashboard project      |
| `dashboard.png`       | Dashboard preview               |
| `dataset.csv / .xlsx` | Source dataset                  |


## 🛠 Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX (Data Analysis Expressions)
* Microsoft Excel / CSV

## 📈 Dashboard Features

* KPI Cards

  * Total Sales
  * Total Profit
  * Total Orders
  * Average Sales

* Interactive Filters (Slicers)

* Sales Trend Analysis

* Category-wise Performance

* Product-wise Analysis

* Regional Sales Analysis

* Customer Insights

* Dynamic Charts & Visualizations

## 📊 Key Insights

The dashboard helps users to:

* Identify high-performing products and categories.
* Compare sales performance across different regions.
* Monitor important business KPIs.
* Discover sales trends over time.
* Support better business decision-making through interactive visualizations.
