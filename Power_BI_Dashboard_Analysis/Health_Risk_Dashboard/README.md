# 🏥 Health Dashboard

## 📊 Project Overview

The **Health Dashboard** is an interactive Power BI dashboard developed to visualize and analyze healthcare data. It provides a comprehensive view of key health-related metrics through intuitive charts, KPIs, and filters, enabling users to monitor performance, identify trends, and make informed decisions.

---

## 🎯 Objectives

* Monitor important healthcare KPIs.
* Analyze patient and treatment data.
* Identify trends and patterns in healthcare services.
* Compare performance across different categories.
* Support data-driven decision-making through interactive visualizations.

---

## 🛠 Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX (Data Analysis Expressions)
* Excel / CSV Dataset

---

## 📈 Dashboard Features

* Interactive KPI Cards
* Dynamic Charts and Graphs
* Trend Analysis
* Category-wise Analysis
* Interactive Slicers and Filters
* Drill-down Reports
* Data Visualization for Better Decision-Making
