# 🛒 Online Store Dashboard

## 📊 Project Overview

The **Online Store Dashboard** is an interactive Power BI project designed to analyze online sales performance and provide meaningful business insights through dynamic visualizations. This dashboard helps monitor key performance indicators (KPIs), identify sales trends, and support data-driven decision-making.

---

## 🎯 Objectives

* Analyze overall sales performance.
* Monitor important business KPIs.
* Identify top-performing products and categories.
* Evaluate regional sales performance.
* Track customer purchasing behaviour.
* Provide actionable business insights.

---

## 🛠 Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX (Data Analysis Expressions)
* Microsoft Excel / CSV Dataset

---

## 📈 Dashboard Features

* Total Sales KPI
* Total Profit KPI
* Total Orders KPI
* Sales Trend Analysis
* Category-wise Sales
* Product-wise Performance
* Regional Sales Analysis
* Interactive Slicers and Filters
* Dynamic Charts and Visualizations
