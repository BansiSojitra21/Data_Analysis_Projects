# 📢 Meta Ads Performance Dashboard

## 📊 Project Overview

The **Meta Ads Performance Dashboard** is an interactive Power BI project designed to analyze the performance of Meta (Facebook & Instagram) advertising campaigns. The dashboard provides comprehensive insights into campaign effectiveness, audience engagement, conversions, and budget utilization, enabling marketers to make informed, data-driven decisions.

---

## 🎯 Project Objectives

* Monitor advertising campaign performance.
* Track key marketing KPIs.
* Analyze audience engagement and conversion metrics.
* Evaluate campaign performance across demographics.
* Identify top-performing markets and advertising strategies.
* Support campaign optimization through interactive reporting.

---

## 🛠 Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX (Data Analysis Expressions)
* Excel / CSV Dataset

---

## 📈 Dashboard Features

* KPI Cards for Campaign Performance
* Campaign Reach & Impressions Analysis
* Click-Through Rate (CTR) Tracking
* Engagement Analysis (Likes, Comments & Shares)
* Conversion & Purchase Analysis
* Gender & Age Group Analysis
* Ad Type Performance Comparison
* Geographic Performance Analysis
* Weekly Performance Trends
* Interactive Filters and Slicers

## 📌 Key Performance Indicators (KPIs)

* **Campaigns:** 50
* **Impressions:** 24,980
* **Clicks:** 3,068
* **Engagements:** 4,508
* **Purchases:** 146
* **Click-Through Rate (CTR):** 10%
* **Engagement Rate:** 18.1%
* **Conversion Rate:** 4.8%
* **Purchase Rate:** 0.5%

These KPIs summarize campaign reach, engagement, and conversion performance.

---

## 💡 Key Insights

* Campaigns achieved strong visibility and user engagement with a **10% CTR** and **18.1% Engagement Rate**.
* Female audiences, particularly those aged **18–34**, generated the highest engagement.
* Campaigns were distributed evenly across Stories, Carousel, Image, and Video formats, allowing performance comparison between ad types.
* The **United Kingdom** emerged as the strongest-performing market, while Australia and Brazil showed additional growth opportunities.
* Although engagement was high, the **0.5% Purchase Rate** indicates room to improve landing pages and conversion strategies.

---

## 🚀 Business Recommendations

* Increase focus on high-performing audience segments.
* Optimize landing pages to improve conversion rates.
* Shift budget toward the best-performing ad formats.
* Prioritize high-performing geographic markets.
* Continue monitoring campaign trends using interactive dashboard filters.

These recommendations are based on the dashboard analysis and are intended to improve campaign effectiveness.
